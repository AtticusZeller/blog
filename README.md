# Blog — Hugo site (`page` branch)

Hugo + PaperMod site for the blog. Posts live on `main` and are generated from LifeOS vault notes by the vault's `blog-publish` skill; this branch holds only the site.

## Build and deploy

The only workflow is `.github/workflows/deploy.yml` on `main`. A push to `main` that touches `posts/` checks out this branch into `site/`, copies `posts/*.md` to `content/posts/` and `posts/images/` to `static/images/`, builds with Hugo, and deploys to Pages. The build passes the Pages URL as `--baseURL`, so `baseURL` in `hugo.yaml` only matters for local builds. Pushing to this branch does not deploy; after changing the site, run:

```bash
gh workflow run deploy.yml -R AtticusZeller/blog --ref main
```

## Domain

The site is https://blog.atticux.me/: a custom domain in this repository's Pages settings (HTTPS enforced) plus Cloudflare DNS `CNAME blog → atticuszeller.github.io`. Old `docs.atticux.me/blog/…` and `atticuszeller.github.io/blog/…` URLs 301-redirect with the path kept. The setup procedure lives in the vault's `blog-publish` skill (`references/custom-domain.md`).

## Post format

Posts arrive as Hugo markdown generated by `blog-publish`; this branch does no conversion.

| Post syntax | Rendering |
|:--|:--|
| `[text](../slug/)` | Relative link to another post, independent of the site's base path |
| `![alt](/images/name.png)` | `render-image.html` prepends the base-URL path (empty at the domain root) and adds `width`/`height` from the file. If `name.webp` exists (blog-publish writes a ≤1600px copy), it renders `<picture>` with the WebP, the original as fallback, and a link to the original for viewing and saving |
| `![alt](/images/name.mp4)` | Same hook renders a `<video controls>` player |
| `$...$` / `$$...$$` | Passed through to MathJax v3; `\begin{equation}` is auto-numbered (`tags: "ams"`) |
| `> [!NOTE]` | GitHub-style alert via `render-blockquote.html` |

## Key files

| File | Purpose |
|:--|:--|
| `hugo.yaml` | Hugo + PaperMod config, MathJax passthrough, highlight theme |
| `layouts/_default/_markup/` | Passthrough, blockquote-alert, and image render hooks (`<picture>` for WebP copies, `<video>` for `.mp4`) |
| `layouts/partials/extend_head.html` | Stylesheet link + MathJax v3 config |
| `static/mathjax/` | Self-hosted MathJax 3.2.2 from the npm package: `es5/tex-mml-chtml.js` plus the lazily loaded `input/` (TeX extensions such as `boldsymbol`), `output/chtml/`, `ui/`, `a11y/`, `sre/`, `adaptors/` |
| `static/css/academic.css` | Visual style |

## Visual style

Academic style inspired by [Lilian Weng's Lil'Log](https://lilianweng.github.io/): Lora serif, crimson `#e0491f` accent, dotted-underline links, ~800px column, GitHub-style code highlighting, pill-shaped tags.
